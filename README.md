# Unslouch

Wearable posture-monitoring system for scoliosis rehabilitation and posture improvement.

## Project overview
Unslouch is a wearable sensor-based product designed to monitor spine angle and provide real-time feedback for better posture and reduced back pain. The system combines sensor data, activity recognition, and personalized exercise guidance to support long-term rehabilitation habits.

## Why this project matters
Scoliosis patients often struggle with consistency in physiotherapy and posture awareness outside the clinic. Unslouch addresses this by making posture monitoring continuous, contextual, and personalized.
